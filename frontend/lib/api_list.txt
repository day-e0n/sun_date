curl -X POST http://220.149.241.209:8000/api/verify-document/ \
	-H "Authorization: Token <YOUR_AUTHENTICATION_TOKEN_HERE>" \

Response:
	성공시:
	{"status":"success","message":"Verification successful.","resident_reg_no_verified":true,"sex_verified":true,"student_id_admission_year_verified":true,"discrepancies":[]}
	실패시:
	{"status":"failed","message":"Verification failed with discrepancies.","resident_reg_no_verified":true,"sex_verified":false,"student_id_admission_year_verified":true,"discrepancies":["Sex from document does not match user's registered sex."]}%
resident_reg_no_verified: 주민등록번호 추출 성공여부
sex_verified: 주민등록번호 뒤의 첫자리를 비교해서 성별 확인
student_id_admission_year_verified: 학번과 입학일자 비교
